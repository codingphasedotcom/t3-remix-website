The **Routines** tab adds a task on a schedule.

## Create a routine

Pick:

- **Title**: the title each new task gets.
- **What to do**: the task's description, the same as you would write on a task.
- **Who does it**: an employee, **You**, or nobody.
- **How often**: every day, every week, every 2 weeks, or every 30 days.
- **Next run**: when it adds its first task.

## How routines run

- When a routine comes due, it adds its task to the board, and the task starts like any other.
- If the last task a routine added is still open when it comes due again, it waits for the next turn instead of adding another. Routines never pile up duplicate work.
- A routine with nobody assigned adds its task to **Ideas**, so it waits for you to schedule it.
- A routine assigned to **You** adds a recurring to-do to your **To do** column.

## Run now

Each routine shows when it last ran and links to the task it created. **Run now** adds its task right away without changing the schedule.

## Ideas for routines

- A weekly review for the CEO: read the board, close what is stale, and propose next week's work.
- A daily dependency and security check for an engineer.
- A routine assigned to **You** for the chores you keep forgetting.
